Master Classes
==============

A master class takes experienced practitioners deep into one technology, using Smarter's
production code as the case study. Where a micro course introduces a subject, a master class
assumes students already work with it, and teaches the decisions they will meet when a real
project outgrows the defaults. Each master class has its own course plans, schedules, live
sessions and grade weights, and uses the rubric levels and course policies in
:doc:`micro-courses/course-formats`.
