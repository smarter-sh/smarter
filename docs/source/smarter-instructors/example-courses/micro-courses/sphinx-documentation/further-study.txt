- **Frameworks:** `Diátaxis <https://diataxis.fr/>`__, Daniele Procida's framework of tutorials,
  how-to guides, reference and explanation, which most good technical documentation follows.
- **Style guides:** the `Google developer documentation style guide
  <https://developers.google.com/style>`__ and the `Microsoft Writing Style Guide
  <https://learn.microsoft.com/en-us/style-guide/welcome/>`__.
- **Tools:** the `Sphinx documentation <https://www.sphinx-doc.org/>`__, its `reStructuredText
  primer <https://www.sphinx-doc.org/en/master/usage/restructuredtext/basics.html>`__, the `Read the
  Docs tutorial <https://docs.readthedocs.io/en/stable/tutorial/>`__, and `Vale
  <https://vale.sh/>`__ for checking prose against a style guide.
- **Community:** `Write the Docs <https://www.writethedocs.org/>`__, its guide, its newsletter and
  its Slack, and the `Good Docs Project <https://www.thegooddocsproject.dev/>`__ templates.
- **YouTube:** conference talks on the `Write the Docs <https://www.youtube.com/@WritetheDocs>`__
  channel, including Daniele Procida's talk on Diátaxis.
- **Reading:** the documentation of Django, Stripe and the Python standard library, often held up as
  models, studied as examples of structure and voice.
- **Smarter:** articles on `blog.smarter.sh <https://blog.smarter.sh/>`__ related to this course:
  `Part 3: What Claude Code Actually Reads
  <https://blog.smarter.sh/2026/10/17/claude-code-data-sources/>`__, on which docs, skills and code
  an agent reads in each session; `Six High-Impact Uses of Claude Code
  <https://blog.smarter.sh/2026/10/23/claude-code-six-uses/>`__, on test coverage, commit messages,
  refactoring, log reviews, translations and front-end design done with an agent; `Smarter's OpenAPI
  Contract: One Extensibility Model for Python, Go, React and VS Code
  <https://blog.smarter.sh/2026/09/05/smarter-openapi-contract/>`__, on the generated, tested
  OpenAPI document that every client depends on. The case studies `Converge or Diverge: AI Coding
  Agents <https://smarter.sh/case-studies/ai-coding-agents>`__, on documentation whose reader is an
  agent, and `One Contract, Five Clients <https://smarter.sh/case-studies/api-contract>`__, on
  reference generated from the code, turn these posts into lessons with labs and discussion
  questions.
