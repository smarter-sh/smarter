- **Official documentation:** `react.dev <https://react.dev/learn>`__, whose *Learn* section is the
  best introduction to modern React, the `Vite guide <https://vite.dev/guide/>`__, the `Bootstrap
  documentation <https://getbootstrap.com/docs/>`__, the `TypeScript handbook
  <https://www.typescriptlang.org/docs/handbook/intro.html>`__, `Testing Library
  <https://testing-library.com/docs/>`__, `Storybook <https://storybook.js.org/docs>`__ and `Mock
  Service Worker <https://mswjs.io/docs/>`__.
- **Reference:** `MDN Web Docs <https://developer.mozilla.org/>`__ for HTML, CSS, JavaScript and web
  APIs, and `web.dev <https://web.dev/>`__ for performance and accessibility.
- **Podcasts:** `Syntax <https://syntax.fm/>`__ with Wes Bos and Scott Tolinski.
- **YouTube:** `Fireship <https://www.youtube.com/@Fireship>`__ for short overviews of tools and
  ideas, and the `React Conf <https://www.youtube.com/@ReactConfOfficial>`__ talks.
- **Writing:** Josh W. Comeau's `blog <https://www.joshwcomeau.com/>`__ on CSS and React, Kent C.
  Dodds's `blog <https://kentcdodds.com/blog>`__ on testing React, and Dan Abramov's `overreacted.io
  <https://overreacted.io/>`__.
- **Accessibility:** the W3C's `WCAG 2.2 quick reference
  <https://www.w3.org/WAI/WCAG22/quickref/>`__ and the `ARIA Authoring Practices Guide
  <https://www.w3.org/WAI/ARIA/apg/>`__.
- **Smarter:** articles on `blog.smarter.sh <https://blog.smarter.sh/>`__ related to this course:
  `Getting Started with @smarter.sh/ui-chat
  <https://blog.smarter.sh/2026/08/08/getting-started-smarter-ui-chat/>`__, on using Smarter's chat
  component in a React app; `How to Embed a Smarter Chatbot in an HTML Web Page
  <https://blog.smarter.sh/2026/07/11/smarter-chat-html/>`__, on putting a chatbot on any web page
  with one script tag; `How to Add a Smarter Chatbot to Your WordPress Site
  <https://blog.smarter.sh/2026/10/26/smarter-chat-wordpress/>`__, with a plugin or a script tag;
  `Django-React Integration <https://blog.smarter.sh/2026/05/29/react-integration/>`__, on how
  Django hosts the console's React apps; `Smarter's List Views: One Design for Queries, Caching,
  Pagination and Refresh <https://blog.smarter.sh/2026/08/15/smarter-list-views/>`__, on the server
  and browser caches behind every console list page.
