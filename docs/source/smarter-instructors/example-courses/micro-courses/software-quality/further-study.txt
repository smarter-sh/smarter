- **Free books:** *Software Engineering at Google* (Winters, Manshreck and Wright, O'Reilly, 2020),
  free at `abseil.io/resources/swe-book <https://abseil.io/resources/swe-book>`__, especially the
  chapters on testing and code review, and Harry Percival's *Obey the Testing Goat* at
  `obeythetestinggoat.com <https://www.obeythetestinggoat.com/>`__.
- **Standards:** `Conventional Commits <https://www.conventionalcommits.org/>`__, `Semantic
  Versioning <https://semver.org/>`__, and the `pre-commit <https://pre-commit.com/>`__ framework's
  documentation.
- **Research:** the annual `DORA State of DevOps reports <https://dora.dev/research/>`__, the
  evidence behind the four key delivery metrics.
- **YouTube:** Dave Farley's `Modern Software Engineering
  <https://www.youtube.com/@ModernSoftwareEngineeringYT>`__ channel on continuous delivery and
  testing, and the PyCon US talks on testing on the `PyCon US <https://www.youtube.com/@PyConUS>`__
  channel.
- **Podcasts:** `Test & Code <https://testandcode.com/>`__ by Brian Okken (its archive is a library
  of Python testing topics), and `Software Engineering Radio <https://se-radio.net/>`__.
- **Writing:** the articles on test doubles, continuous integration and refactoring at
  `martinfowler.com <https://martinfowler.com/>`__, including Ham Vocke's `The Practical Test
  Pyramid <https://martinfowler.com/articles/practical-test-pyramid.html>`__.
- **Smarter:** articles on `blog.smarter.sh <https://blog.smarter.sh/>`__ related to this course:
  `Django and AWS: Keeping the Cloud Out of Reach of Application Code and Tests
  <https://blog.smarter.sh/2026/09/03/cloud-out-of-reach-of-tests/>`__, on the service layer and
  guard that keep AWS and Kubernetes out of the tests; `Six High-Impact Uses of Claude Code
  <https://blog.smarter.sh/2026/10/23/claude-code-six-uses/>`__, on test coverage, commit messages,
  refactoring, log reviews, translations and front-end design done with an agent; `Part 1:
  Maintaining Long-Term Code Quality With Agentic AI
  <https://blog.smarter.sh/2026/10/10/claude-code-large-django-codebase/>`__, on what an agent
  multiplies in a large codebase, and what kept Smarter's code converging; `Part 2: The Antipattern
  That Makes a Codebase Diverge
  <https://blog.smarter.sh/2026/10/11/blog-prologue-geometric-series/>`__, on the pattern that makes
  a series of agent changes diverge, and how to find it; `Smarter's OpenAPI Contract: One
  Extensibility Model for Python, Go, React and VS Code
  <https://blog.smarter.sh/2026/09/05/smarter-openapi-contract/>`__, on the generated, tested
  OpenAPI document that every client depends on. The case studies `Converge or Diverge: AI Coding
  Agents <https://smarter.sh/case-studies/ai-coding-agents>`__, on tests and guards as an agent's
  feedback, `One Contract, Five Clients <https://smarter.sh/case-studies/api-contract>`__, on
  contract tests, and `What Happens When You Click Deploy
  <https://smarter.sh/case-studies/deploy>`__, on keeping the cloud out of tests, turn these posts
  into lessons with labs and discussion questions.
