Every lecture, lab and assignment in this course rests on the files and commits below. Every
reference is to the ``main`` branch of a public repository in
`github.com/smarter-sh <https://github.com/smarter-sh>`__, so that students can open each one
during class. Python paths in the ``smarter`` repository are under ``smarter/smarter/``. The
figures quoted in the lectures were counted on ``main`` in October 2026, excluding release
commits, migrations and generated files; students recount them in the labs.

The Foundation
~~~~~~~~~~~~~~

.. list-table::
   :header-rows: 1
   :widths: 22 43 35

   * - 4. Subsystems by hand
     - The human-designed subsystems that every application inherits: tenancy and ownership,
       the response journal, encrypted Secrets referenced by name, and a typed settings layer.
       "The agent writes the difference. The foundation cancels the rest."
     - `apps/account/models/metadata_with_ownership.py <https://github.com/smarter-sh/smarter/blob/main/smarter/smarter/apps/account/models/metadata_with_ownership.py>`__,

       `common/conf/ <https://github.com/smarter-sh/smarter/tree/main/smarter/smarter/common/conf>`__
   * - 5. One way to do each thing
     - The manifest loader and the abstract broker that every resource kind extends, with
       ``kubectl``-style verbs, so that a new kind is the difference from the last one.
       :doc:`ADR 005 </adr/005-manifests>`, :doc:`ADR 024 </adr/024-broker-model>`.
     - `lib/manifest/loader.py <https://github.com/smarter-sh/smarter/blob/main/smarter/smarter/lib/manifest/loader.py>`__,
       `lib/manifest/broker/abstract_broker_class.py <https://github.com/smarter-sh/smarter/blob/main/smarter/smarter/lib/manifest/broker/abstract_broker_class.py>`__,
       `apps/guardrail/ <https://github.com/smarter-sh/smarter/tree/main/smarter/smarter/apps/guardrail>`__
   * - 6. Types and contracts
     - Type annotations as a rule, typed aliases instead of ``Any``, Pydantic models instead of
       raw JSON, and an OpenAPI document that tests every route from the outside. The API bugs
       that the Python SDK found when it called the platform as a stranger would.
       :doc:`ADR 027 </adr/027-annotations>`, :doc:`ADR 031 </adr/031-pydantic-over-json>`.
     - `lib/typing.py <https://github.com/smarter-sh/smarter/blob/main/smarter/smarter/lib/typing.py>`__,
       `apps/api/v1/contract/ <https://github.com/smarter-sh/smarter/tree/main/smarter/smarter/apps/api/v1/contract>`__,
