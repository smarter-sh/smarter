Every lecture, lab and assignment in this course rests on the files and commits below. Every
reference is to the ``main`` branch of a public repository in
`github.com/smarter-sh <https://github.com/smarter-sh>`__, so that students can open each one
during class. Python paths in the ``smarter`` repository are under ``smarter/smarter/``.

Talking to the LLM
~~~~~~~~~~~~~~~~~~

.. list-table::
   :header-rows: 1
   :widths: 22 43 35

   * - Module
     - What to read
     - Where to look
   * - 4. The openai package
     - A passthrough client that adapts a request to the provider's current API (OpenAI's
       reasoning models refuse ``max_tokens``), the SDK's exceptions mapped to HTTP status codes,
       and a small client that calls embeddings, moderation and chat completions.
     - `apps/provider/clients.py <https://github.com/smarter-sh/smarter/blob/main/smarter/smarter/apps/provider/clients.py>`__,
       `apps/provider/services/text_completion/lib/exception_map.py <https://github.com/smarter-sh/smarter/blob/main/smarter/smarter/apps/provider/services/text_completion/lib/exception_map.py>`__,
       `apps/guardrail/services/strategies/clients.py <https://github.com/smarter-sh/smarter/blob/main/smarter/smarter/apps/guardrail/services/strategies/clients.py>`__
   * - 5. Pydantic and JSON
     - An LLM judge that asks for JSON mode and parses the verdict. The chat API's contract:
       Pydantic models with no ``dict[str, Any]``, ``extra="forbid"`` on models of ORM rows, a
       committed JSON Schema and a test that it is current.
       :doc:`ADR 031 </adr/031-pydantic-over-json>`.
       `Commit 0630dcb55 <https://github.com/smarter-sh/smarter/commit/0630dcb55ff54f81bae9ce3c3b62e55331c2203a>`__
       made the contract explicit, and its body lists what the implicit one had allowed.
     - `apps/guardrail/services/strategies/llm_judge_strategy.py <https://github.com/smarter-sh/smarter/blob/main/smarter/smarter/apps/guardrail/services/strategies/llm_judge_strategy.py>`__,
       `apps/prompt/contract/ <https://github.com/smarter-sh/smarter/tree/main/smarter/smarter/apps/prompt/contract>`__
       (``models.py``, ``schema.py``, ``chat-contract.schema.json``)
   * - 6. Keeping secrets secret
     - Settings typed as ``SecretStr``; ``is_missing_value()``, which treats ``SET-ME-PLEASE``
       placeholders as unset; Secrets encrypted with Fernet; and a Proxy that adds the
       provider's key on the server.
       `Commit 990cab95b <https://github.com/smarter-sh/smarter/commit/990cab95bd8c7286dd7f71a7edd371e374cdc422>`__
       found that a placeholder key was stored and sent as a real one.
       `Commit 07a42204c <https://github.com/smarter-sh/smarter/commit/07a42204cdfb8e48f51cdaa92b873f6a7efcb619>`__
       built the Proxy. :doc:`ADR 007 </adr/007-settings>`, :doc:`ADR 016 </adr/016-security>`.
     - `common/conf/settings.py <https://github.com/smarter-sh/smarter/blob/main/smarter/smarter/common/conf/settings.py>`__,
       `common/conf/env.py <https://github.com/smarter-sh/smarter/blob/main/smarter/smarter/common/conf/env.py>`__,
       `.env.example <https://github.com/smarter-sh/smarter/blob/main/.env.example>`__,
       `apps/secret/models.py <https://github.com/smarter-sh/smarter/blob/main/smarter/smarter/apps/secret/models.py>`__,
       `apps/proxy/services.py <https://github.com/smarter-sh/smarter/blob/main/smarter/smarter/apps/proxy/services.py>`__

   * - 13. Streaming and progress
     - A prompt runs in a worker thread while an async generator streams its progress as
       Server-Sent Events, forwarded from signals; the Proxy streams a provider's own SSE
       response; and the chat component reads a stream.
     - `apps/prompt/progress.py <https://github.com/smarter-sh/smarter/blob/main/smarter/smarter/apps/prompt/progress.py>`__,

   * - 14. Building a chat UI with chatscope
     - Smarter Chat is built from three open-source packages. Its main component composes
       chatscope's containers, message list, input and typing indicator. Its styles override
       chatscope's theme with CSS variables. Its message helpers escape the user's text and render
       the LLM's Markdown with ``marked`` and ``DOMPurify``, and its Console shows requests and
       responses with ``react-json-view``.
       `Commit afb1b5e63 <https://github.com/smarter-sh/smarter-chat/commit/afb1b5e637e97e629b24b50cb98ec0adfb985528>`__
       applied an LLMClient's colors to chatscope's components.
     - `smarter-chat: package.json <https://github.com/smarter-sh/smarter-chat/blob/main/package.json>`__,
       `src/components/SmarterChat/ <https://github.com/smarter-sh/smarter-chat/tree/main/src/components/SmarterChat>`__
       (``Component.tsx``, ``styles.css``),
       `src/lib/styles.ts <https://github.com/smarter-sh/smarter-chat/blob/main/src/lib/styles.ts>`__,
       `src/lib/messages.ts <https://github.com/smarter-sh/smarter-chat/blob/main/src/lib/messages.ts>`__,
       `src/components/Console/Component.tsx <https://github.com/smarter-sh/smarter-chat/blob/main/src/components/Console/Component.tsx>`__
