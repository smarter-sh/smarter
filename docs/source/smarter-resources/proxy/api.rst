API Reference
=============

The Proxy passthrough endpoint, ``/api/v1/proxy/<name>/<path>``, and the list of the Proxies
that a caller may use, ``/api/v1/proxy/``. They are enabled when ``SMARTER_ENABLE_PROXY`` is
true, which is the default.
