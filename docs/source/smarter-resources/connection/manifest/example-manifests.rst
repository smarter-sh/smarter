Example Manifests
=================

These ApiConnection and SqlConnection examples are kept with this documentation, in
`docs/source/example-manifests/ <https://github.com/smarter-sh/smarter/tree/main/docs/source/example-manifests>`__,
for you to read and copy, and no platform applies them. The example manifests that every
Smarter platform loads when ``manage.py initialize_platform`` runs live in
`smarter-sh/example-manifests <https://github.com/smarter-sh/example-manifests>`__, the community-supported
:doc:`example manifests repository </smarter-framework/smarter-manifests/example-manifests>`, which has no connections.
