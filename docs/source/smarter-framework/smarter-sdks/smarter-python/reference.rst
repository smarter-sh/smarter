API Reference
=============

The SDK's API reference, generated from its docstrings, is on its own documentation site: every
class and method of the client and its resources, the models of every manifest kind and of the
platform's API contracts, and the exceptions.

- `Client and configuration <https://docs.smarter-python.smarter.sh/reference/client.html>`__
- `Resources <https://docs.smarter-python.smarter.sh/reference/resources.html>`__
- `Models <https://docs.smarter-python.smarter.sh/reference/models.html>`__
- `Contracts <https://docs.smarter-python.smarter.sh/reference/contracts.html>`__
- `SAM kinds <https://docs.smarter-python.smarter.sh/reference/sam.html>`__
- `Core: transport, errors and logging <https://docs.smarter-python.smarter.sh/reference/core.html>`__

It is generated there, not here, because the SDK and the platform are both the Python package
``smarter``, and this site's build imports the platform's.
