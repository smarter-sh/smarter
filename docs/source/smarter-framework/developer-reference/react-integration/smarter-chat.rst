Smarter Chat
============

Smarter Chat, the React app of the LLMClient prompt engineering workbench, is also published to npm
as `@smarter.sh/ui-chat <https://www.npmjs.com/package/@smarter.sh/ui-chat>`__, and has its own
section of the documentation: :doc:`Smarter Chat <../../smarter-chat>`.

It is hosted like the other React apps on this page, from its package in the React workspace,
`smarter/react/packages/smarter.sh-chat <https://github.com/smarter-sh/smarter/tree/main/smarter/react/packages/smarter.sh-chat>`__,
with two differences: it is a library, which the workbench app (``@smarter/workbench``) imports, and
its name is its npm package name, ``@smarter.sh/ui-chat``, rather than ``@smarter/<name>``.
See :doc:`How the Web Console Hosts It <../../smarter-chat/web-console-hosting>` and
:doc:`Developing Smarter Chat <../../smarter-chat/development>`.
