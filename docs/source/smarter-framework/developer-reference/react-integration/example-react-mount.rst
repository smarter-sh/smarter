Example React Component Mounting in Smarter
==============================================

The entry point of the single-page web console, which mounts the app and its router, is in the
web console's repository,
`packages/smarter-console/src/main.tsx <https://github.com/smarter-sh/smarter-console/blob/main/packages/smarter-console/src/main.tsx>`__.
Its routes are in
`packages/smarter-console/src/router.tsx <https://github.com/smarter-sh/smarter-console/blob/main/packages/smarter-console/src/router.tsx>`__.
