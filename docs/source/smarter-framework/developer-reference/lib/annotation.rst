Smarter Annotations Library
===========================

Kubernetes-style annotations on every Smarter resource: their validation, their storage as rows of
:class:`~smarter.lib.annotation.models.Annotation`, queries and selectors, and the handlers and signal
that integrations use to react when they change. See
:ref:`Annotations <sam-annotations>` for how manifests use them.
