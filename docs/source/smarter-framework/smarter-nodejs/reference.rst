API Reference
=============

The SDK's classes, methods, functions and schemas, from its TSDoc comments. These pages are
generated by the SDK's ``scripts/generate-reference.ts`` (``npm run reference``): see
:doc:`Developing the SDK <development>`.

Every name is exported by the package, e.g. ``import { Smarter, NotFoundError, Manifest } from
"smarter-api"``. A model is a Zod schema and a TypeScript type of the same name.
