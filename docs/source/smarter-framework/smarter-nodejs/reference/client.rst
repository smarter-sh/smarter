.. js:class:: Smarter(options)

   A client of a Smarter platform's api.

   The client's properties group the api's operations:

   - ``Smarter.manifests``: apply, validate, get, describe, delete, deploy, undeploy and logs, for any kind
   - ``Smarter.llmClients``: LLMClients, and prompting and chatting with them
   - ``Smarter.guardrails``, ``Smarter.mcpClients``, ``Smarter.vectorstores``,
     ``Smarter.llmHosts``, ``Smarter.secrets``, ``Smarter.plugins``,
     ``Smarter.orchestrators``, ``Smarter.vectorsearches``
   - ``Smarter.accounts`` (and ``accounts.users``, ``accounts.contacts`` and ``accounts.userProfiles``)
   - ``Smarter.history``, ``Smarter.journal``, ``Smarter.providers``, ``Smarter.proxies``
   - ``Smarter.whoami``, ``Smarter.version``, ``Smarter.status`` and ``Smarter.kinds``

   A client holds no open connections of its own: there is nothing to close.

   :param options: The api key, base url, environment, timeout (seconds), retries, headers, ``fetch`` and logging.
   :type options: SmarterOptions
   :throws SmarterConfigurationError: If no api key is found, or an option or environment variable is invalid.
