Smarter for IT Leadership

4

About 3 minutes. Walk left to right. On the left, every way people and programs reach Smarter: the web console, the CLI and VS Code extension, a REST API with a published OpenAPI document, SDKs in three languages, an embeddable React chat component, and, through the Proxy, the vendors’ own SDKs unchanged. In the middle, the platform, organized as four resource layers. Underneath it is a conventional, supportable stack: Django and Django REST Framework, Celery workers for asynchronous work, MariaDB, Redis, all containerized and run on Kubernetes. On the right, everything Smarter brokers access to: commercial model vendors, self-hosted open models, and your own systems. The architectural point: all traffic between people and models, and between models and your systems, passes through one governed layer.
