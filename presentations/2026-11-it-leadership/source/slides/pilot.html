Getting started

A 90-day technical pilot

[Weeks 1–2]

Stand up

Non-production install with Helm on an existing cluster. Route one provider through the Proxy.

[Weeks 3–8]

Build

A literacy cohort delivers [1–2] business use cases, with one read-only data connection.

[Weeks 9–11]

Assess

Security review against your controls. Cost, usage and audit reports from real traffic.

[Week 12]

Decide

Production architecture, SSO approach and support model.

Smarter for IT Leadership

15

About 2 minutes. Each of the four roles has a job in the pilot. Infrastructure stands it up and owns the security review. Application development reviews the manifests and builds the data connection. Technical support uses the prompt records and cost data during the build phase, so it has an informed view by week 12. The CIO gets a decision based on the organization’s own traffic, costs and audit records rather than a vendor’s projections. Routing one existing application through the Proxy in week one is a quick, low-risk way to see cost attribution working before anything new is built. Adjust the timings to the organization.
