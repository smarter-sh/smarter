Standard integration points

REST API

Every operation, with a published OpenAPI document and JSON Schemas.

SDKs and CLI

Python, Node.js and Go SDKs; a CLI; a VS Code extension that validates manifests.

Drop-in proxy

Existing OpenAI, Anthropic or Gemini SDK code works unchanged: swap the base URL and key.

Embeddable chat

A React component and NPM package put an assistant on any web page.

Model Context Protocol

Consume any MCP server’s tools, under the same governance.

Open framework

Django, DRF and Pydantic, the same framework Smarter is built on, for extensions.

About 2 minutes. The message for development leads: nothing here is proprietary glue. The REST API is fully documented in OpenAPI, so it fits API gateways and client generators. The Proxy is the fastest win: applications already written against a vendor’s SDK keep working, but their keys, spending and logs move under governance by changing two configuration values. MCP support means tools your teams or vendors already expose over the Model Context Protocol plug straight in. And when you do need custom code, it is mainstream Python on Django, not a niche runtime.
