About 2 minutes. For the head of infrastructure. The same container images run everywhere, from a laptop under Docker Compose to production Kubernetes under the official Helm chart. For AWS, the project publishes Terraform and Terragrunt modules that build the whole environment, including the EKS cluster, DNS, certificates, storage and email, with remote state in S3. Operationally: app servers and workers scale horizontally, compute can run on spot instances, and one installation separates alpha, beta, next and production environments with clean namespace and resource naming. Be candid that a production install requires real Kubernetes, Terraform and AWS skills; the documentation says so, and recommends a hosting partner for organizations without them.
