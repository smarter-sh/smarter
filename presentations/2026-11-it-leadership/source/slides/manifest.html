Smarter for IT Leadership · Manifest abridged

6

About 2 minutes. This is the one slide with code, and it is deliberately short. It is an abridged but real-format manifest for an assistant: which model, which tool it may use, and which guardrails screen its input and output. Two commands create it and publish it. For IT, the significance is operational: AI applications become reviewable, diffable configuration that fits your existing change-management process, rather than bespoke code in every team’s repository. For the business, it means a trained analyst can read and change it. The manifest names the plugin and guardrails by reference; those are separate resources, often owned by different people.
