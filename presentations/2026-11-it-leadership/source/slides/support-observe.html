About 2 minutes. For the head of technical support. When a user reports that “the AI gave a wrong answer,” support today often has nothing to look at. In Smarter, the prompt record is the starting point of a trace: which assistant answered, which guardrails fired, which tools were called with what results, which model replied, and which account and budget authorized it. Cost accounting is stored per request in ordinary database tables, so chargeback reports are a SQL query. Logging verbosity for a specific subsystem can be switched on at runtime from the admin console. And because every user has their own API keys, a compromised or departing user’s access is revoked individually, without rotating anyone else’s.
